# Запуск Smart Meter Configurator в Windows

[English version](RUN_WINDOWS.md) · [Описание проекта](../README.ru.md)

## Перед началом

Для работы необходимы:

- Windows 10/11 (64 бит) или Windows 7 (64 или 32 бита);
- сборка программы для соответствующей версии Windows;
- поддерживаемый СКВТ ЭМИС-ЭЛЕКТРА 977;
- адаптер RS-485 с установленным драйвером;
- подключение прибора согласно его эксплуатационной документации.

Установка Python для готовой сборки не требуется.

## Первый запуск

1. Скачайте подходящий ZIP-архив из раздела
   [Releases](https://github.com/Sugo174/Smart-electric-meter-configurator/releases).
2. Полностью распакуйте архив в постоянную папку,
   доступную пользователю для записи.
3. Сохраните все файлы сборки вместе.
   Для Windows 10/11 обязательна папка `_internal`.
4. Подключите адаптер RS-485 к компьютеру и прибору.
5. Запустите исполняемый файл приложения.
6. Выберите исполнение прибора: одноканальное или двухканальное.
7. Выберите COM-порт адаптера и нажмите «Подключиться».
8. После подключения проверьте информацию о приборе и показания.

Перед подключением освободите выбранный COM-порт в других
программах. Обнаруженный порт отображается в списке,
даже если в данный момент занят.

## Завершение работы с прибором

Нажмите «Отключиться» и дождитесь завершения отключения.

Если программа сообщает, что опрос ещё завершается,
подождите немного и повторите отключение.

После успешного отключения COM-порт можно использовать
в другой программе.

## Обновление программы

Программа проверяет новые выпуски на GitHub при запуске.
Ручная проверка доступна через меню настроек программы.

Обновление устанавливается вручную:

1. Завершите операции с прибором и закройте программу.
2. Скачайте архив новой версии для своей Windows.
3. Распакуйте его в отдельную папку.
4. Запустите новую версию и проверьте подключение к прибору.

Не смешивайте файлы разных версий или сборок для разных
операционных систем.

## Решение проблем

### COM-порт отсутствует в списке

- Проверьте подключение адаптера к компьютеру.
- Проверьте наличие адаптера и номер порта в диспетчере устройств Windows.
- Установите драйвер адаптера, если Windows не распознала устройство.
- Нажмите «Обновить» в программе.

### COM-порт отображается, но подключиться не удаётся

- Отключитесь от этого порта в других программах.
- Проверьте питание прибора и подключение RS-485.
- Проверьте выбранное исполнение прибора.
- Уточните адрес, скорость и чётность обмена.

Наличие COM-порта в списке означает, что Windows обнаружила
устройство, но не подтверждает доступность порта или связь
со счётчиком.

### Программа не запускается

- Проверьте, что скачана сборка для вашей версии Windows.
- Полностью распакуйте ZIP-архив перед запуском.
- Не переносите исполняемый файл отдельно от остальных файлов сборки.
- Для Windows 10/11 проверьте наличие папки `_internal`.
- При появлении ошибки сохраните её полный текст.

### Новая версия не обнаруживается

Проверьте доступность GitHub и подключение к интернету.
При необходимости откройте страницу Releases вручную.

Ошибка проверки обновлений не препятствует работе с прибором.
